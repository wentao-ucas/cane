## 核心公式

### 完整公式

```
进口成本(元/吨) = (CBOT价格 × 0.367437 + CNF升贴水) × 汇率 × (1 + 关税率) × (1 + 增值税率) + 港杂费
```

### 英文表达

```
Import Cost (CNY/MT) = (CBOT Price × 0.367437 + CNF Premium) × FX Rate × (1 + Tariff) × (1 + VAT) + Port Charges
```

## 参数说明

### 1. CBOT大豆价格 (CBOT Soybean Price)

- **单位**：美分/蒲式耳 (cents/bushel)
- **数据源**：CME Group - ZS合约
- **查询地址**：https://www.cmegroup.com/markets/agriculture/oilseeds/soybean.html

**单位换算**：
```
1 蒲式耳(bushel) = 27.2155 公斤
1 吨 = 36.7437 蒲式耳
转换系数 = 0.367437 (美分/蒲 → 美元/吨)

示例：CBOT = 1000 美分/蒲
      = 1000 × 0.367437 = 367.44 美元/吨
```

### 2. CNF升贴水 (CNF Premium/Discount)

- **单位**：美元/吨 (USD/MT)
- **含义**：到岸价相对于CBOT的溢价，包含运费和基差
- **来源**：
  - 巴西大豆：Brazil FOB + Freight
  - 美湾大豆：US Gulf FOB + Freight

**典型范围**：
- 巴西大豆：80-200 美元/吨（含运费）
- 美湾大豆：60-150 美元/吨（含运费）

### 3. 汇率 (Exchange Rate)

- **数据**：USD/CNY 中间价
- **来源**：中国人民银行
- **查询**：https://www.chinamoney.com.cn/

### 4. 关税 (Tariff)

| 来源国 | 关税率 | 英文 | 备注 |
|--------|--------|------|------|
| 巴西 | 3% | MFN Rate | 最惠国税率 |
| 阿根廷 | 3% | MFN Rate | |
| 美国 | 3% + 25% = 28% | MFN + Additional Tariff | 2018年7月起加征 |

> 注：2020年1月中美第一阶段协议后，部分美豆进口关税有减免配额

### 5. 增值税 (VAT)

- **税率**：9%（2019年4月起，之前为10%）
- **英文**：Value-Added Tax

### 6. 港杂费 (Port Charges)

- **范围**：100-150 元/吨
- **包含**：卸货费、港口使用费、检验检疫费等
- **英文**：Port Handling Charges, Inspection Fees

## 计算示例

### 示例：2026年1月巴西大豆进口成本

**输入参数**：
- CBOT大豆：980 美分/蒲式耳
- CNF升贴水：150 美元/吨（含运费）
- 汇率：7.25
- 关税：3%（巴西）
- 增值税：9%
- 港杂费：120 元/吨

**计算过程**：
```python
# Step 1: CBOT转美元/吨
cbot_usd_mt = 980 * 0.367437  # = 360.09 美元/吨

# Step 2: 加上CNF升贴水
cnf_price = 360.09 + 150  # = 510.09 美元/吨

# Step 3: 转人民币
cny_price = 510.09 * 7.25  # = 3698.15 元/吨

# Step 4: 加关税
after_tariff = 3698.15 * 1.03  # = 3809.09 元/吨

# Step 5: 加增值税
after_vat = 3809.09 * 1.09  # = 4151.91 元/吨

# Step 6: 加港杂费
final_cost = 4151.91 + 120  # = 4271.91 元/吨
```

**结果**：进口成本约 **4272 元/吨**

## 成本敏感性分析

### 各因素影响权重（以当前参数为基准）

| 因素 | 变动 | 成本变化 | 影响 |
|------|------|----------|------|
| CBOT价格 | +100美分/蒲 | +299元/吨 | 最大 |
| CNF升贴水 | +50美元/吨 | +408元/吨 | 大 |
| 汇率 | +0.5 | +352元/吨 | 大 |
| 关税 | +10% | +370元/吨 | 大（政策风险） |

### Python 计算函数

```python
def calc_import_cost(
    cbot_cents: float,      # CBOT价格，美分/蒲式耳
    cnf_premium: float,     # CNF升贴水，美元/吨
    fx_rate: float,         # 汇率 USD/CNY
    tariff: float = 0.03,   # 关税率，默认3%
    vat: float = 0.09,      # 增值税率，默认9%
    port_charge: float = 120 # 港杂费，元/吨
) -> float:
    """计算进口大豆成本（元/吨）"""
    # CBOT转美元/吨
    cbot_usd_mt = cbot_cents * 0.367437
    # CNF价格
    cnf_price = cbot_usd_mt + cnf_premium
    # 转人民币并加税
    cost = cnf_price * fx_rate * (1 + tariff) * (1 + vat) + port_charge
    return round(cost, 2)
```

## 注意事项

1. **时间差**：CBOT收盘时间与国内早盘存在时差，注意使用对应时点数据
2. **基差结构**：CNF升贴水包含了船期因素，不同月份差异较大
3. **船期影响**：巴西到中国约35-45天，美湾约30-35天
4. **汇率波动**：建议使用当日中间价或前一日收盘价
5. **政策变化**：关税政策可能随贸易谈判调整
