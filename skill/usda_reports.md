# USDA报告解读指南

> USDA Reports Interpretation Guide

---

## 什么是USDA？

**USDA (United States Department of Agriculture)** 美国农业部，是全球农产品市场最权威的信息来源。

---

## 核心报告

### 1. WASDE月报 —— 最重要

**WASDE** = World Agricultural Supply and Demand Estimates  
世界农产品供需预测报告

| 属性 | 说明 |
|------|------|
| 发布时间 | 每月10-12日，美东时间12:00 (北京时间次日凌晨0:00) |
| 内容 | 全球主要农产品的产量、消费、库存、贸易预测 |
| 涵盖作物 | 大豆、玉米、小麦、棉花、大米、油籽等 |
| 重要性 | ⭐⭐⭐⭐⭐ |

## 如何解读USDA报告

### 报告前准备

1. **收集市场预期**
   - Bloomberg/Reuters分析师调查均值
   - 主要机构预测（Allendale, StoneX等）
   - 期货市场隐含预期

2. **计算预期差**
   ```
   预期差 = 实际值 - 市场预期均值
   预期差越大，价格波动越剧烈
   ```

### 解读逻辑

```
产量上调 → 供给增加 → 利空 (Bearish) → 价格下跌
产量下调 → 供给减少 → 利多 (Bullish) → 价格上涨

库存上调 → 供过于求 → 利空 → 价格下跌
库存下调 → 供不应求 → 利多 → 价格上涨

出口上调 → 需求增加 → 利多 → 价格上涨
出口下调 → 需求减少 → 利空 → 价格下跌
```

### 库存消费比判断

| 库存消费比 | 供需状态 | 价格影响 |
|------------|----------|----------|
| < 20% | 偏紧 | 支撑价格 |
| 20-25% | 平衡 | 中性 |
| 25-30% | 偏松 | 压制价格 |
| > 30% | 宽松 | 明显利空 |

## 注意事项

1. **时差问题**：USDA报告发布时间是美东时间，换算北京时间需+12/13小时
2. **报告修正**：USDA会修正历史数据，关注修正幅度
3. **预期管理**：市场常"买预期卖事实"，利多出尽反而下跌
4. **综合判断**：单一报告不决定趋势，需结合其他因素
5. **南美天气**：12月-3月关注巴西/阿根廷天气对产量影响
