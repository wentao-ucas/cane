# 猪周期分析方法

> Pig Cycle Analysis Method

---

## 什么是猪周期

**猪周期 (Pig Cycle / Hog Cycle)** 是指生猪养殖行业由于供需关系变化而呈现出的周期性价格波动现象。

### 周期形成机制

```
猪价高 → 养殖利润好 → 补栏增加 → 供应增加 → 猪价下跌
   ↑                                              ↓
猪价低 ← 养殖亏损 ← 产能去化 ← 供应减少 ← 猪价低
```

### 典型周期时长

- **完整周期**：3-4年
- **上行周期**：1-2年
- **下行周期**：1.5-2.5年

## 核心指标体系

### 1. 能繁母猪存栏 (Breeding Sow Inventory)

**最核心的领先指标**

| 属性 | 说明 |
|------|------|
| 定义 | 具备繁殖能力的母猪数量 |
| 单位 | 万头 |
| 来源 | 农业农村部月度数据 |
| 领先性 | 领先生猪出栏约10个月 |

**时滞关系**：
```
能繁母猪存栏变化
    ↓ (4个月) 配种+妊娠期
仔猪出生
    ↓ (6个月) 育肥期
生猪出栏
    ↓ 
猪肉供应 / 豆粕需求
```

### 2. 生猪存栏 (Hog Inventory)

| 属性 | 说明 |
|------|------|
| 定义 | 所有在养生猪数量 |
| 单位 | 万头 |
| 来源 | 农业农村部月度数据 |
| 同步性 | 与豆粕需求基本同步 |

### 3. 生猪价格 (Hog Price)

| 属性 | 说明 |
|------|------|
| 定义 | 生猪出栏价格 |
| 单位 | 元/公斤 |
| 来源 | 涌益咨询、卓创资讯 |
| 作用 | 反映当前供需状态 |

### 4. 猪粮比 (Hog-Corn Ratio)

| 属性 | 说明 |
|------|------|
| 定义 | 生猪价格 / 玉米价格 |
| 盈亏平衡 | 约6:1 |
| 来源 | 发改委 |
| 作用 | 判断养殖盈亏 |

**猪粮比解读**：
| 猪粮比 | 盈利状态 | 养殖行为 |
|--------|----------|----------|
| > 9:1 | 高利润 | 大量补栏 |
| 7-9:1 | 正常盈利 | 正常补栏 |
| 6-7:1 | 微利/盈亏平衡 | 谨慎 |
| < 6:1 | 亏损 | 淘汰产能 |

## 历史猪周期回顾

### 2006年以来的主要周期

| 周期 | 时间跨度 | 低点 | 高点 | 驱动因素 |
|------|----------|------|------|----------|
| 第1轮 | 2006-2010 | 2006.05 | 2008.03 | 蓝耳病疫情 |
| 第2轮 | 2010-2014 | 2010.06 | 2011.09 | 正常周期 |
| 第3轮 | 2014-2018 | 2014.04 | 2016.05 | 环保去产能 |
| 第4轮 | 2018-2022 | 2018.05 | 2019.10 | 非洲猪瘟 |
| 第5轮 | 2022-? | 2022.10 | 2024.08 | 产能恢复后调整 |

### 第4轮周期详解（非洲猪瘟周期）

```
2018.08 - 非洲猪瘟首次确诊
    ↓
2018-2019 - 大量产能去化，能繁母猪存栏降至2000万头以下
    ↓
2019.10 - 猪价创历史新高（40元/公斤以上）
    ↓
2019-2021 - 大规模补栏，产能快速恢复
    ↓
2021-2022 - 猪价持续下跌，行业深度亏损
    ↓
2022.10 - 猪价触底，新一轮周期开始
```

## 猪周期与豆粕需求的关系

### 传导链条

```
能繁母猪存栏 ↑ 
    ↓ (4个月)
仔猪出生量 ↑
    ↓ (立即)
仔猪饲料需求 ↑（豆粕需求增加）
    ↓ (6个月)
育肥猪存栏 ↑
    ↓ (持续)
育肥饲料需求 ↑（豆粕需求持续增加）
```

### 关键时滞

| 阶段 | 时滞 | 豆粕需求变化 |
|------|------|--------------|
| 能繁母猪补栏 | 0 | 微增（母猪料） |
| 仔猪出生 | +4个月 | 增加（仔猪料） |
| 育肥期 | +4-10个月 | 大幅增加（育肥料） |
| 出栏高峰 | +10个月 | 需求见顶 |

### 相关性分析

历史数据显示：
- **能繁母猪存栏** vs **豆粕价格**：领先约6-10个月
- **生猪存栏** vs **豆粕价格**：基本同步，相关系数约0.6-0.7
- **猪价** vs **豆粕价格**：弱相关（受供给端影响更大）

## Python 分析代码

### 数据加载与处理

```python
import pandas as pd
import matplotlib.pyplot as plt

def load_pig_cycle_data(csv_path: str) -> pd.DataFrame:
    """加载猪周期数据"""
    df = pd.read_csv(csv_path, parse_dates=['date'])
    df.set_index('date', inplace=True)
    return df

def calc_yoy_change(series: pd.Series) -> pd.Series:
    """计算同比变化"""
    return series.pct_change(periods=12) * 100

def calc_mom_change(series: pd.Series) -> pd.Series:
    """计算环比变化"""
    return series.pct_change() * 100
```

### 周期位置判断

```python
def judge_cycle_phase(
    sow_inventory: float,
    sow_yoy: float,
    hog_price: float,
    price_yoy: float
) -> str:
    """
    判断当前猪周期位置
    
    Args:
        sow_inventory: 能繁母猪存栏（万头）
        sow_yoy: 能繁母猪同比变化(%)
        hog_price: 生猪价格（元/公斤）
        price_yoy: 猪价同比变化(%)
    
    Returns:
        str: 周期阶段判断
    """
    if sow_yoy > 5 and price_yoy > 20:
        return "周期上行中期 - 产能扩张，猪价高位"
    elif sow_yoy > 5 and price_yoy < 0:
        return "周期顶部 - 产能过剩，猪价回落"
    elif sow_yoy < -5 and price_yoy < -20:
        return "周期下行中期 - 产能去化，猪价低迷"
    elif sow_yoy < -5 and price_yoy > 0:
        return "周期底部 - 产能收缩，猪价企稳"
    else:
        return "周期过渡期 - 供需调整中"
```

## 对豆粕投资的指导意义

### 周期位置与豆粕策略

| 猪周期阶段 | 能繁母猪 | 豆粕需求 | 豆粕ETF策略 |
|------------|----------|----------|-------------|
| 底部→上行 | 开始补栏 | 即将增加 | **逐步建仓** |
| 上行期 | 持续增加 | 快速增加 | **持有** |
| 顶部 | 高位 | 需求高峰 | **逢高减仓** |
| 下行期 | 去化中 | 逐步下降 | **观望/轻仓** |
| 底部 | 低位企稳 | 需求底部 | **关注建仓机会** |

### 实战要点

1. **领先布局**：能繁母猪连续3个月环比回升时，可以开始关注豆粕
2. **右侧确认**：生猪存栏同比转正后，确认需求回升
3. **结合供给**：需求回升但供给宽松时，价格可能不涨
4. **警惕疫情**：疫情会打乱正常周期节奏

## 注意事项

1. **数据修正**：官方数据可能会有事后修正
2. **季节性**：春节前后是传统消费旺季
3. **疫情影响**：非洲猪瘟等疫情会打乱周期
4. **规模化趋势**：规模场占比提升，周期可能变长
5. **政策调控**：收储/放储会影响短期价格
6. **替代效应**：禽肉、牛羊肉的替代影响
