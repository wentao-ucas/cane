## 🔄 XML 数据结构说明

### 年度版本标识
```xml
market_year1="2023/24"           <!-- 历史实际值 -->
market_year1="2024/25 (Est.)"    <!-- 估计值 -->  
market_year1="2025/26 (Proj.)"   <!-- 预测值 -->
```

### 月份版本 (预测更新)
```xml
forecast_month1="Dec"  <!-- 12月版预测 -->
forecast_month1="Jan"  <!-- 1月版预测 (最新) -->
```

### 属性标签
```xml
attribute1="Output"          <!-- 产量 -->
attribute1="Total Supply"    <!-- 总供给 -->
attribute1="Trade"           <!-- 贸易量 -->
attribute1="Total Use"       <!-- 总消费 -->
attribute1="Ending Stocks"   <!-- 期末库存 -->
```

## 💡 使用建议

1. **快速定位**: 使用 grep 搜索 `<Report Name="sr28"` 找到全球大豆表
2. **获取最新预测**: 查找 `forecast_month2="Jan"` 获取1月最新预测
3. **对比变化**: 比较 Dec 和 Jan 版本，了解USDA调整方向
4. **中国数据**: 在 sr28 中搜索 `region2=" China"` 或 `region4=" China"`
