## 一、看多逻辑：治雨的核心观点(基本面)

> 来源：雪球@治雨 2026-06-02《中国玉米市场十年周期复盘与2026年展望：缺口博弈与国家意志》
> 全文 8 部分，核心是用十年数据论证"中国玉米每年有6000-8000万吨刚性缺口"，并追踪缺口的填补路径如何一步步转移、最终在2025年走到库存见底，从而看多2026。

### 1.0 核心论断：从净出口国到每年6000-8000万吨缺口

伴随中国人餐桌改善 + 玉米深加工产业发展(年加工需求从4000万吨跃升至8000万吨)，中国已由粮食净出口国转为净进口国。**国内玉米每年存在6000-8000万吨的刚性产需缺口**，必须靠"进口或国储拍卖"等方式填补。

作者用**缺口填补路径的三轮接力**(临储玉米→临储小麦→进口+稻谷+保税粉)来反证这个缺口真实存在且长期稳定。

### 1.1 第一棒(2017-2020)：临储玉米拍卖 —— 缺口的"试金石"

2016年前为保护农民，国家临储收购形成高达 **2.36亿吨** 的"堰塞湖"。2017年5月启动拍卖至2020年9月收官，逐年成交：

| 年份 | 拍卖成交 | 注释 |
|---|---|---|
| 2017 | **5740万吨** | 首年，库存从2.36亿降至约1.79亿 |
| 2018 | **10014万吨** | 首破亿吨，峰值，对政策粮源依赖达顶 |
| 2019 | **2191万吨** | 非洲猪瘟冲击(能繁母猪-40%、年末生猪存栏-27.5%)，需求短期萎缩 |
| 2020 | **5694.8万吨** | "最后的疯狂"，成交率94.8% |

**四年平均每年额外消化约5900万吨。** 这证明2017年后国内消费已持续性超过当年产量，临储拍卖的巨量成交，就是这块6000万吨级缺口的"试金石"。

### 1.2 第二棒(2020.9-2021)：临储小麦接棒

临储玉米一退场，6000万吨缺口并未消失。国家立刻加大临储小麦投放：
- 周度投放从100万吨增至300-400万吨，**定向山东、河南**等饲料需求旺盛区
- 成交：2020年 **2185万吨**、2021年 **2849万吨**，两年合计超 **5000万吨**
- 2021年1-5月就成交2779万吨(几乎完成全年) → 春季玉米青黄不接时替代需求极迫切
- 流向：陈化小麦粉碎掺入饲料，直接替代玉米

### 1.3 第三棒(2021-2024)：进口谷物 + 定向稻谷

临储小麦耗尽后，调控接力棒交给"全球市场资源"：

**进口爆发**(以2020年玉米1130+小麦838+大麦808+高粱481 = 3257万吨为基数)：
- 2021年进口飙至 **6002万吨**(同比近+100%)
- 2021-2024 相对2020的进口增量：**2745 / 1391 / 2319 / 1515 万吨**

**定向饲用稻谷拍卖**(动用国内稻谷库存替代玉米)：
- 2021年约 **1612万吨**、2022年 **2888万吨**(当年关键)、2023年约 **1478万吨**

**但出现矛盾**——把"进口增量+稻谷拍卖"加总，公开渠道填补量：

| 年份 | 进口增量 | 稻谷拍卖 | 公开渠道合计 |
|---|---|---|---|
| 2021 | 2745 | 1612 | 4357万吨 |
| 2022 | 1391 | 2888 | 4279万吨 |
| 2023 | 2319 | 1478 | 3797万吨 |
| 2024 | 1515 | 0 | 1515万吨 |

公开渠道年均仅约4000万吨，**填不满6000万吨缺口**。可既然填不满，为何2022-2024玉米价格反而被压、贸易商还连年"高价收、低价卖"深亏？**一定有规模巨大的隐性供给未被统计。**

### 1.4 缺口之谜的答案：保税区玉米粉(全文核心爆点)

**操作手法**：贸易商把进口玉米粒运至保税区，利用区内加工政策**粉碎成玉米粉**，再以"饲料原料"或"其他工业品"名义报关入境。精妙之处：
- **规避配额**：玉米粉不属于玉米粒的关税配额管理范畴，绕开配额限制
- **降低税费**：玉米粉的关税+增值税通常低于玉米粒，有套利空间
- **统计隐身**：在海关被归入其他税号，真实量从未在官方谷物进口数据中完全显现

**估算规模**(行业调研+多方交叉验证，无官方数据)：
- 2021年约 **2300万吨** → 2022年 **2600万吨** → 2023年 **3500万吨** → 2024年 **2400万吨**

**把三项供给(进口谷物+定向稻谷+保税粉)加总**，2021-2023稳定在 **6600-7300万吨**，恰好匹配每年约6000万吨缺口 —— **谜题解开**。而2024年总供给骤降至3915万吨，正对应国家10月后收紧进口的时点。

**最深远的影响——定价权转移**：保税粉的巨量存在，使国内玉米在青黄不接期**不再由"收粮成本+仓储利息"定价，而被锚定到"进口玉米粉到港成本"**。只要国内价高于这个成本，套利就驱动隐形进口持续涌入、无情压制国内价。**这正是2022-2024无数贸易商"高价收粮、低价抛售"每吨亏200-300元、连亏三年的根本原因。**

### 1.5 需求端铁证：缺口只会扩大，不会缩小

作者用三组独立数据证明需求引擎持续做大：

**① 大豆进口(养殖蛋白需求的温度计)**——尽管推行豆粕减量替代，仍连年走高：
- 2021: 9652 → 2022: 8922 → 2023: 9941 → 2024: 10503 → **2025: 11183万吨(破1.1亿吨创历史新高)**

**② 工业饲料总产量**：
- 2021: 2.93亿吨 → 2022: 3.02亿(首破3亿) → 2023: 3.22亿 → 2024: 3.15亿(结构调整回调) → **2025: 3.42亿吨**
- 五年 **+16.6%**(+4880万吨)

**③ 国内玉米产量**：
- 2021: 2.73亿吨 → **2025: 约3.01亿吨**，五年 **+10.5%**(+2800万吨)

**结论**：需求增速(+16.6%) **显著快于** 国内产量增速(+10.5%)。需求引擎功率始终大于国内供给马力，**6000万吨缺口非但不会缩小，反而有继续扩大的可能。**

### 1.6 2025年：全社会渠道深度去库存(行情的引信)

- **2024-10政策纠偏**：国家紧急叫停玉米及替代物进口，**11月一刀切封堵保税玉米粉灰色通道**
- **2025进口断崖**：玉米+麦+大麦+高粱合计仅 **2159万吨**(同比2024年7172万吨 **-69.9%**)；玉米单项 **264.87万吨**(同比 **-80.58%**，近11年新低)
- **需求仍刚性**：2025饲料产量3.42亿吨(+8.6%)、玉米产量3.01亿吨创新高，但相较近3.6亿吨的饲用+工业消费总量，缺口依然巨大
- **只能消耗库存填补**：从港口保税仓、贸易商到下游饲料厂的积压库存被逐层挖掘。测算至2025年末，**社会渠道流通库存毛估减少约1.16亿吨**
- **2025年9-10月高潮**："2025年9月末全市场找不到陈玉米""若新粮再晚上市20天，陈玉米能涨飞边子""贸易商每天睁眼30多个需求电话，积压一年的差玉米被一扫而空" → **充裕的陈粮库存消耗殆尽，渠道库存降至极低**

### 1.7 2026展望："一场迟来的回归"

**供给侧三重收紧**：
1. **渠道库存空虚**：2026起点是"蓄水池近乎干涸"，缓冲垫微乎其微
2. **进口铁幕持续**：进口和隐形玉米粉的"价格稳定器"作用消退，国内供需重新与全球价格脱钩，**定价权重归国内基本面**
3. **季节性卖压出清**：5月被糙米拍卖等预期压制，但6月华北腾库结束、东北自然干粮源耗尽，市场迎来**阶段性供给空窗期**

**需求与成本双重支撑**：
- **需求刚性**：前4月大豆进口仍快速增长，庞大养殖存栏决定玉米消费韧性
- **高持粮成本**：当前流通粮源成本由2026年3月收购锁定，含资金利息折锦州港 **2400元**，而盘面仅 **2326元** → **全部贸易商深度亏损、出货意愿极低**(锦州港连续十余天集港量汽车不足百台，近一周仅50台水平)

**天气情绪催化**：厄尔尼诺已从预期转为现实，将成为二季度末种植生长期的炒作主题(⚠️ 本项目对此因子方向存疑，见3.2)

**作者核心判断**：2026夏季处于"低库存、紧进口、高成本、弱预期"多重矛盾交织的节点。当5月季节性卖压褪去，季节性供给断档 + 刚性需求将形成尖锐矛盾，真实供需面貌水落石出。**逼空很大概率提前至8月甚至7月末上演**，一旦价格启动将冲击"玉米涨不动"的旧共识，引发贸易商和用粮企业同步补库的正向反馈。对伤痕累累的贸易商，这将是一场迟来的"回血"。

### 1.8 顶层逻辑：让粮价合理上涨是国家意志

- 中国粮食定价**不能简单锚定国际市价**：人均耕地仅约2.38亩、小农经营为主体的国情，决定了定价必须以"**保障农民生计尊严、维护种粮积极性、确保粮食安全**"为逻辑起点，主粮价格理应在国际粮价基础上包含合理的"**国情溢价**"
- 2025玉米进口同比骤降约90%、进口玉米粉清零，正是这一逻辑的坚决实践
- 政策认识：无保护的廉价进口在降低短期成本前，会率先摧毁国内农业生产体系和数百万家庭生计，最终动摇粮食安全根基。**"粮食价格首先是安全与生存问题，其次才是经济问题"**
- 从临储去库存→进口管控，从反内卷国策→捍卫粮食安全，一系列政策指向同一方向：**系统性纠正粮食价值长期低估，构建"以国内生产为主、合理溢价、农民受益、安全可控"的市场新格局**
- **未来主旋律不再是周期性暴涨暴跌，而是国家意志引导下，价格中枢稳步上移、产业各环节利润合理修复的新历史阶段**

### 1.9 治雨逻辑链一句话串联

> 每年6000万吨刚性缺口(深加工+养殖做大) → 十年靠三棒接力填补(临储玉米→临储小麦→进口+稻谷+**保税粉**) → 保税粉让国内定价权失守、贸易商连亏三年 → 2024.10国家政策纠偏、封堵进口 → 2025全渠道去库存1.16亿吨、陈粮见底 → 2026库存空窗+进口铁幕+高成本+国家意志 → **看多，价格中枢上移**

## 二、量化验证：本项目21年研究(对照)

### 2.1 内外盘高度独立 —— 印证保税粉机制

- C0 vs CBOT 玉米相关性仅 **0.30**(白糖0.47)，临储期(2011-2015)低至0.24
- **本研究只观测到"国内被压在进口成本线"的现象，治雨补上了机制(保税玉米粉锚定国际粮价)** —— 两者完美互补

### 2.2 季节性：做多最佳建仓点是9-10月，不是现在

21年回测，每月底建仓做多的前瞻收益：

| 建仓月 | 未来3月均值/胜率 | 未来6月均值/胜率 |
|---|---|---|
| **9月底** 🥇 | +4.3% / **86%** | +6.2% / 76% |
| 10月底 | +3.9% / 81% | +5.2% / 81% |
| 8月底 | +2.2% / 71% | +5.3% / 76% |
| **5月底(现在附近)** | **-2.3% / 33%** | -0.1% / 43% |

**结论**：常规年份，5-6月是全年第二差的做多窗口(要扛6-7-9月季节性弱月)；最优是9-10月新粮上市低点建仓，持有到次年1-2月旺季。

### 2.3 ⚠️ ENSO分歧：厄尔尼诺对玉米是利空，不是利多

- 本研究21年ONI回归：玉米**同期** La Niña利多(月均+2.7%)、**El Niño利空**(强El Niño月均-2.97%，胜率35%)
- 机制：厄尔尼诺通常给美国玉米带带来凉湿丰产天气 → 压制价格
- **治雨把"厄尔尼诺转为现实"当利多催化，与历史统计相反** —— 这是看多逻辑里一个可质疑的点(博弈情绪而非统计规律)

## 三、核心赌注：2026 是不是 2020？

治雨逻辑本质 = 赌"2026复制2020"(库存见底引发逼空，打破季节性)。本项目对2020做了**合约级复盘**。

### 3.1 2020逼空的真相：7月启动，但近月短命、远月笑到最后

| 合约 | 5/15入场→高点 | 涨幅 | 见顶时间 |
|---|---|---|---|
| C2009(9月陈粮) | 2027→2340 | **+15.4%** | 2020-07-27就见顶 |
| C2011(11月) | 2045→2577 | +26.0% | 10月 |
| **C2101(1月冬储)** | 2064→2855 | **+38.3%** 🏆 | 2021-01 |
| C2105(5月) | 2105→2881 | +36.9% | 2021-01 |

**铁律：逼空行情里，近月领涨但短命(放鞭炮的)，1月冬储合约笑到最后(收钱的)。** 9月陈粮合约只吃+15%且7月底见顶，还被交割规则8月赶下车；1月合约闷声+38%。

这与季节性回测("9月底建仓持有到次年旺季胜率86%、长持1月优于短持9月")**三重印证**。

### 3.2 陈粮逼仓会不会压制远月C2701？—— 会，但取决于新粮够不够

**2020价差演变**：7月陈粮逼仓时，近月C2009被逼到升水远月+75(back结构)，远月短暂被压；但8月近月见顶、9月新粮上市后远月暴力反超-155(系统缺口下新粮也不够，资金接力)。

**7年实证：压不压得住，取决于当年新粮丰产预期**

| 年份 | 新粮预期 | 5→8月 远月命运 |
|---|---|---|
| 2020 | 临储清空，系统缺口 | ✅ 远月跟得上(最终+38%) |
| 2022 | 稻谷补，平衡 | ✅ 远月反而强 |
| **2021** | 进口巅峰 | 🔴 近月跑赢，远月被压(+3.0) |
| **2023** | 增产开始 | 🔴 近月跑赢，远月被压(+4.5) |
| 2025 | 创纪录3.01亿吨 | 远月反而强(但都在跌) |

**结论**：新粮丰产预期强的年份(2021、2023)，陈粮逼仓就是近月独角戏，远月被压死。系统缺口年(2020)远月接力大涨。

### 3.3 2026 的核心矛盾

| 看多(治雨) | 看空(反方) |
|---|---|
| 库存见底，系统缺口 | 2025已增产3.01亿吨创纪录，2026或继续增产 |
| 新粮上市也填不满 → 2020式 | 新粮丰产兑现 → 2023式 |
| 进口铁幕，国家意志推涨 | **小麦2500天花板压制**(新麦不到2500，玉米两次脉冲卡2500) |
| 厄尔尼诺天气炒作 | 陈稻/糙米定向拍卖或重启放储(国家还有底牌) |

**押C2701本质 = 赌"2026是2020不是2023"。6-8月即使逼仓来了，陈粮阶段C2701大概率被压、走back结构，要扛震荡。**

## 四、交易结构与合约选择

### 4.1 玉米合约的硬约束：只有 7/9/1 月流动性能打 + 散户不能进交割

- 玉米活跃合约集中在 **7月、9月、1月**；3月、11月是半僵尸合约(成交几千手)，别碰
- **散户(自然人)不允许实物交割**：C2609(9月交割)散户必须在**8月最后交易日前平仓**，实务上期货公司7-8月就提保证金/限开仓，**实际持有窗口 = 6月~8月中**
- 想拿到秋冬旺季(10月-次年1月)，**物理上只能用C2701**(2027年1月交割，散户能拿到2026年12月底)

### 4.2 C2701流动性：对散户够用，且会成长

历年1月合约都是"前一年6月还小，9-11月暴涨成主力"：

| 合约 | 6月持仓 | 峰值持仓(9-11月) |
|---|---|---|
| C2601 | 8.8万 | 102万 |
| **C2701** | **6万(日成交1万手)** | 待成长 |

- 散户做几手到几十手，6万手持仓/1万手日成交**绰绰有余**
- 历史规律：1月合约7月破20万手成主力，9-11月冲80-150万手 → **流动性成长曲线与逼空时间线同步**
- 注意：C2701现在6万手是历年同期最低，反映当前市场极清淡(贸易商出清)，要耐心熬冷清期；进场分批，别一次大单

【第一波】6-8月: 主仓 C2609(陈粮近月)
  - 理由: 流动性最好(6月新主力)、逼仓直接受益标的、确定性高
